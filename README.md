# FIX-LEGACY
FIX LEGACY é uma aplicação de consulta de dados de sistemas legados, criada para acesso seguro a informações históricas de ERPs antigos após migrações. O sistema é focado em leitura (read-only), com filtros e pesquisas estruturadas, permitindo validações, auditorias e análises sem impacto na operação atual. Ideal para equipes técnicas e de negócio
